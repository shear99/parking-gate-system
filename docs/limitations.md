## 현장 인식 한계

- 번호판 검출 성공, 문자 인식 성공, 허용 여부 판단은 서로 다른 단계입니다.
- 조도와 모션 블러의 영향이 남아 있어 야간 자동 인식은 사용하지 않습니다.
- 적외선 장치 추가나 더 빠른 셔터를 지원하는 카메라로 교체하는 방안은 도입 검토를 요청한 상태입니다. 도입·개선 완료로 표시하지 않습니다.
- 도로의 여러 차량이 처리 대상이 되는 문제는 진입 구간의 ROI를 설정해 범위를 줄였습니다. 정밀 추적기 개발이나 대규모 성능 최적화로 확대하지 않습니다.
- 공개된 정확도·지연시간 벤치마크는 없습니다. 모델 confidence는 정답률이 아니며, 이 저장소에서 모델 추론 성능을 새로 측정하지 않았습니다.

## 제외된 구현과 증명 범위

- 개발 기간은 2026.05~2026.08이며, 공개 소스 검토일 2026-10-10은 개발 기간 연장이나 최신 운영 배포 완료를 뜻하지 않습니다.
- R6 웹 제어 코어와 기존 영상처리 소스의 역할을 함께 설명하지만, 인식 파이프라인이 R6 API로 통합 배포됐다고 주장하지 않습니다.

- 학습 중인 후보 모델, shadow 시스템, 새 제어기 재작성 프로토타입은 운영 구현과 분리했습니다.
- 학습 데이터·실제 번호판·원본 영상·모델 가중치를 공개하지 않습니다.
- 출차 차량 매칭이나 총 주차시간 산정 기능을 구현했다고 주장하지 않습니다. 기록의 단위는 차단기 개폐와 관련 이벤트입니다.
- 전체 시스템 설치·배포·운영 절차와 현장 복구용 설정은 제공하지 않습니다.
